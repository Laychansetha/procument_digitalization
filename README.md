## 📱 System Overview (High Level)

1. **Web Operations & Admin Portal**: Built with Next.js 16, TypeScript, TailwindCSS, and PostgreSQL (Prisma ORM) for central administration, scale receiving, and finance disbursement verification.
2. **Android Field Application**: Built with Flutter for offline-first quality inspection, purchase recording, and automated master data synchronization.
